# برنامج الرواتب

برنامج رواتب لسطح المكتب (ويندوز) بواجهة عربية، يصدّر **ملف تحميل بطاقات الرواتب** بالتنسيق الذي يقبله البنك لرفعه مباشرة.

## المزايا

- **ملف لكل موظف**: الرقم الوظيفي، الاسم كما في البنك، رقم الهوية، الفرع، الراتب الأساسي، بدل السكن، البدلات الأخرى، رقم بطاقة الراتب وتاريخ انتهائها، وطريقة الصرف (بطاقة أو غير ذلك).
- **تنبيهات البطاقات**: البطاقات المنتهية أو التي تنتهي خلال الشهر الحالي أو الشهر القادم، والموظفون بدون تاريخ انتهاء مسجل.
- **السلف**: مبلغ السلفة والقسط الشهري وشهر بداية الخصم، يُخصم القسط تلقائياً في المسير ويقل الرصيد عند اعتماد المسير، مع إمكانية تعديل قسط شهر معين أو إيقاف الخصم مؤقتاً.
- **مسير شهري**: أيام العمل (يُحسب الراتب بالتناسب مع أيام الشهر)، إضافي/مكافأة، خصومات أخرى مع السبب، استبعاد موظف من شهر معين، ثم الاعتماد.
- **تصدير ملف البنك** (`.txt`) مع فحص الأخطاء قبل التصدير (رقم البطاقة 19 رقماً، الهوية 10 أرقام، الأسماء، البطاقات المنتهية).
- **الكشوفات** (طباعة أو حفظ PDF): كشف مسير الشهر مجمّع حسب الفرع بالإجماليات، قسيمة راتب لكل موظف، وكشف رواتب الموظف شهراً بشهر. وتصدير المسير إلى Excel (CSV).
- **استيراد** الموظفين من ملف بنك سابق، و**نسخ احتياطي** يومي تلقائي مع حفظ/استعادة يدوية.

تُحفظ البيانات على الجهاز في مجلد `المستندات\برنامج الرواتب\data.json`، ونسخة احتياطية يومية في `نسخ احتياطية`.

## تنسيق ملف البنك

كل سطر 194 بايت ينتهي بـ CRLF، بترميز Windows-1256، بدون سطر رأس أو إجمالي. المبالغ بالهللة، والأرقام مكمّلة بأصفار من اليسار:

| الحقل | الطول |
|---|---|
| الرقم الوظيفي | 12 |
| رقم البطاقة (19 رقماً مكمّلة بأصفار) | 24 |
| اسم الموظف (مكمّل بمسافات) | 50 |
| رقم الهوية | 10 |
| المبلغ (الصافي) | 15 |
| تاريخ التحويل YYYYMMDD | 8 |
| نوع العملية (`2` = تحميل رصيد) | 1 |
| رقم الإدارة | 5 |
| ثابت `0` | 1 |
| مسافات | 20 |
| الراتب الأساسي | 12 |
| بدل السكن | 12 |
| بدلات أخرى | 12 |
| الاستقطاعات | 12 |

ويجب أن يساوي المبلغ: الأساسي + السكن + الأخرى − الاستقطاعات. الموظفون بدون بطاقة أو بصافي صفر لا يدخلون الملف، والترتيب حسب الفرع ثم الرقم الوظيفي.

## التشغيل والتطوير

```bash
npm install
npm start          # تشغيل البرنامج
npm test           # الاختبارات
npm run dist       # بناء نسخة ويندوز (على جهاز ويندوز)
```

عند كل دمج على `main` يبني GitHub Actions نسخة ويندوز وينشرها في صفحة Releases باسم رقم الإصدار الموجود في `package.json`.

> هذا المستودع لا يحتوي على أي بيانات موظفين حقيقية. البيانات تبقى على جهازك فقط.
